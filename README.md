## 📌 About

**PhisingWraith.py** is a terminal-based cybersecurity simulation framework for authorized security labs, phishing-awareness demonstrations, education, and defensive research.

### ✨ Features

- 🎨 Animated terminal interface
- 🧩 Interactive exercise/template selection
- 🛠️ Environment and dependency checks
- 🖥️ Local PHP laboratory server
- 🌐 Local/LAN exercise workflow
- 🔗 Optional tunnel support
- 📱 Termux-aware setup
- 🪟 Windows support
- 🐧 Linux support
- 🍎 macOS support
- 🔄 Status/update checks
- 🛡️ Consent and disclaimer workflow
- 🧹 Cleanup-oriented laboratory workflow

## 🚀 Installation

### Windows

Install Python 3.x and PHP, then verify:

```powershell
python --version
php --version
```

Clone the repository:

```powershell
git clone <YOUR-REPOSITORY-URL>
cd PhisingWraith
```

Run:

```powershell
python PhisingWraith.py
```

### Linux / Kali / Ubuntu

```bash
sudo apt update
sudo apt install python3 php curl unzip git -y
```

Then:

```bash
git clone <YOUR-REPOSITORY-URL>
cd PhisingWraith
python3 PhisingWraith.py
```

### Fedora

```bash
sudo dnf install python3 php curl unzip git -y
python3 PhisingWraith.py
```

### Arch Linux

```bash
sudo pacman -S python php curl unzip git
python3 PhisingWraith.py
```

### macOS

With Homebrew:

```bash

```

Then:

```bash

cd PhisingWraith
python3 PhisingWraith.py
```

### Termux / Android

```bash

pkg install python php curl unzip git -y
```

## 📂 Repository Structure

The README logo is intentionally stored using a **relative GitHub path**:

```text
PhisingWraith/
│
├── PhisingWraith.py
├── README.md
│
└── assets/
    └── PhisingWraith.png
```

### ⚠️ Important

Do **not** rename the logo or folder unless you also update the README.

The README currently expects exactly:

```text
assets/PhisingWraith.png
```

GitHub is case-sensitive.

## 🛡️ Safe Simulation

Use only:

- Authorized systems
- Dedicated laboratory accounts
- Synthetic credentials
- Test devices
- Participants who have consented

Never use real passwords, OTPs, recovery codes, session cookies, or private tokens during an exercise.

The recommended architecture is:

```text
Simulation
    ↓
Consent
    ↓
Synthetic Input
    ↓
Awareness Event
    ↓
Training Result
```

## 🐛 Troubleshooting

### Logo does not appear

Make sure your repository contains:

```text
README.md
assets/
└── PhisingWraith.png
```

And that the README contains:

```html
<img src="./assets/PhisingWraith.png" alt="PhisingWraith.py Logo" width="900">
```

### PHP not found

```bash
php --version
```

Install PHP for your operating system.

### Python not found

Linux/macOS/Termux:

```bash
python3 --version
```

Windows:

```powershell
python --version
```

### Port unavailable

Choose an unused port and restart the laboratory server.
