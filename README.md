## 📌 Overview

**PhisingWraith.py** is a terminal-based cybersecurity simulation framework designed for **authorized security labs, phishing-awareness demonstrations, education, and defensive research**.

The project combines an interactive terminal interface with environment checks, simulation templates, local laboratory hosting, and safety-oriented exercise workflows.

---

## ✨ Features

- 🎨 Animated terminal interface
- 🖥️ Interactive CLI workflow
- 🧩 Simulation/template selection
- 🛠️ Automatic environment and dependency checks
- 🌐 Local/LAN laboratory hosting
- 🐘 PHP development server support
- 🔗 Optional tunnel integration
- 📱 Termux-aware environment handling
- 🪟 Windows support
- 🐧 Linux support
- 🍎 macOS support
- ⚙️ Configurable port workflow
- 🔄 Status/update checking
- 🛡️ Consent and disclaimer workflow
- 🧹 Laboratory cleanup workflow

# 🛡️ Safe Simulation Model

PhisingWraith.py should be used as an awareness simulator rather than a credential-harvesting system.

Recommended workflow:

```text
Participant
     ↓
Simulation Page
     ↓
Consent / Disclosure
     ↓
Synthetic Test Input
     ↓
Awareness Event
     ↓
Training Result
```

Use synthetic values such as:

```text
username: training-user
password: DEMO_ONLY
```

Never use:

```text
Real Password
Real OTP
Recovery Code
Session Cookie
Private Token
```
